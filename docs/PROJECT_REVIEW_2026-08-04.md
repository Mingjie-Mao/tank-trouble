## 一、项目是什么

把 2000 年代 Flash 游戏 Tank Trouble 反编译，逐行移植成 Python（约 2500 行引擎，
含 980 行的原版脚本 AI「Laika」），在这个**精确、可复现、无头高速**的环境上回答一个问题：

> AI 能否自主学会击败一个手写游戏 AI——能到什么程度，什么方法最有效？

评估口径自始至终不变：**真胜率**（原版计分，先杀后死 = 双亡不得分），
1000+ 局全新种子定级，换冠军需第二种子基复验。
参照系：random 0.5% ｜ 手写猎杀脚本 22.5% ｜ **Laika 镜像自打 40.2%**。

## 二、完整迭代过程（六个阶段）

### 阶段 0 · 复刻期：先造一把准的尺子

反编译 SWF → 逐行对照重写 → 25 项忠实度验证。复刻精度做到了帧序、
坦克 5 子步碰撞、子弹 7 子步反弹、AS2 的 `undefined==0` 语义和 NaN 传播。

这一步是后面所有方法的前提：**只有引擎精确，搜索才能当老师；只有零依赖纯 Python，
才能 fork 多进程跑到 6000+ 帧/秒；只有种子可复现，1000 局定级才有意义。**

### 阶段 1 · 无模型 RL：5% → 36.4%，然后撞墙

| 关键节点 | 真胜率 | 结论 |
|---|---:|---|
| v1 纯胜负 ±1 | 12.4 | 学成苟活不开火 |
| v2 开火塑形 | 22.1 | 首次突破，但换成神风流 |
| v4 终局改原版计分 | 23.8 | 修正目标定义 |
| **P2 弹道预演观测**（76→121 维） | **30.4** | **最大单项 +8** |
| **P8 自伤弹惩罚 -0.45** | **35.1** | 剂量峰值（-0.15/-0.45/-0.75 = 31.5/35.1/31.9） |
| P9–P14 八连试 | 31–34 | ❌ 奖励工程饱和 |
| P15 BC 克隆 Laika + 价值预热 + PPO 微调 | 33.8 | 3 倍学习速度，新策略盆地 |
| P16 60M 步长训 | 30.0/21.0 | ❌ **微调有效窗口 ≈2M 步** |
| **P17 导航观测**（最短路方向 +4 维） | **36.4/37.8** | ✅ **RL 线终点** |
| P18 CNN 地图头 | 22.5 | ❌ 惨败于 4 维手工导航特征 |

阶段结论：**信息 > 激励 > 容量**。"学不会"大多是"看不见"；
已收敛策略的单点行为矫正（P13/P14）会破坏自平衡，改观测才涨分。

### 阶段 2 · 决策时搜索：96%，击穿天花板

无未来函数沙盒 + 18 个动作各前推 48 帧，零训练直接 **96.0%**。
P20 用 P17 网络剪枝到 top-K 再深推：K=12 完全追平全量搜索且快 4.3 倍（36ms/决策，实时可用）。

**范式转向**：搜索不是选手，是**测量仪**（量出游戏的规划上限）和**老师**（产标签）。

### 阶段 3 · 蒸馏：9% → 62% → 74.7%

| 节点 | 结果 | 教训 |
|---|---:|---|
| P19 argmax 行为克隆 | 裸装 8.9 | **并列陷阱**：MPC 打平时随机选边，标签在关键状态自相矛盾 |
| P21a 评分回归探针 | 14.0 | 诊断精确：学会了状态级价值（R²≈46%）却学不会状态内动作排序 |
| **P21b 408 维全知观测 + 评分回归** | **62.2/63.8** | ✅ 首个纯网络突破，8.6ms/决策零搜索 |
| **P22 DAgger 专家迭代** | 门 +4/+1/平台，重建后 **74.7/75.6** | ✅ 飞轮跑通并如期见顶 |

两个方法论产出：
- **标签形式**：回归 18 个动作的结局评分（价值地形），而不是模仿一个 argmax 动作。
- **度量形式**：top-1 准确率在多解任务上数学不可用（标签中位 14/18 并列，完美预测器上限 11.9%），
  正确指标是**后悔值**（P21b：93.6% 决策选中够好动作，中位后悔 0）。

### 阶段 4 · 改造老师目标：一串负结果换来 76.9%

| 分支 | 结果 | 判定 |
|---|---:|---|
| P23 学习价值叶子 | 老师 93.5→87.5 | ❌ 价值泄漏 + on-policy 价值陷阱（把被动固化） |
| 免疫探针（Laika 不自杀） | 95.8→97.9 | ⚠️ 推翻"老师靠等送死赢"的观感判断 |
| P24 生存课程 / 衰减计分板 | 老师 1.6s/命中，学生 58.7 | ❌ 老师机制成立，蒸馏没继承 |
| P24v3 免疫穿透 + 弹夹税 | 8.1s/命中 | ❌ 2s 免疫超出老师 48 帧视野，节奏塌掉 |
| P25 机会势能 | 52.5 | ⚠️ 目标可行，学生过度开火 |
| **P25v2 360° 炮线老师** | **76.9/77.4** | ✅ 击杀方式从直射转为主动反弹杀线 |

阶段结论：**课程分数 ≠ 原版分数**，每条课程分支都必须有原版规则验收；
录像观感 ≠ 测量（免疫探针）。

### 阶段 5 · 摊销搜索 + 风险头：87% → 88.2/89.6（现任部署冠军）

- **P26 amortized MPC iter05**：87.1/86.4，`fire_margin=0.16`
- P27 宏动作头 ❌（接管太频繁，72.5%）／fire assist ❌（多打但打得差）／
  suppress-only ❌（40 局 90% 但 300 局塌到 84%）
- **P27b 风险/价值头**：作为**分数微调**而非动作接管，**1000@970000 = 88.2%，500@990000 = 89.6%**
- P28 prior-search 混合体（确定性 h72, samples=2）：硬种子段 97.5%，但 **25s/局**，不可部署
- P29 / P29b / P29c 蒸馏 ❌（标签语义混杂：h48/h72/h96 平均出的"光滑但不决断"目标）
- P30 共识修正（默认保留 P27b 动作，只预测 keep/override）：进行中

### 阶段 6 · 精确状态特权老师：99%

克隆本地引擎的**完整状态，含 RNG 和 Laika 隐藏内部状态**（20 种子 × 20000 帧指纹零失配），
加上安全屏蔽（严格拒绝预测死亡/双亡）、必要时扩展全 18 动作、后继一帧可行性护盾、
已锁定击杀后抑制冗余开火。

- 固定基准 **120/120 = 100%**
- 未见种子 **297/300 = 99.0%**，0 双亡
- Sparse 版（9.33% 帧才全搜）**119/120**；narrow-replan 变体在新种子 152 局出现第 4 个非胜后按预注册规则停止 ❌
- 精确老师蒸馏先导：三个候选（硬安全门 / 全网络微调 / 冻干校准）全被在线门拒绝 ❌

## 三、用了什么技术，以及为什么

| 技术 | 为什么选它 | 证据 |
|---|---|---|
| **逐行反编译移植**，不用现成模拟器 | 搜索需要精确前向模型 + 可克隆状态；封装的模拟器给不了 RNG 和对手内部状态 | 精确老师 99% 完全建立在这上面 |
| **纯 Python 零依赖引擎** | 可无限 fork 多进程、无头 6000+ 帧/秒、无 GPU 依赖 | 单机 12 workers 跑 120 局精确搜索 = 22 分钟 |
| **PPO (SB3) 双塔 [256,256]** | RL 线的标准强基线，先把"能不能纯 RL 学会"这条路问干净 | A 线终点 36.4%，问题不在算法而在信息 |
| **BC 热启动 + 价值预热 50 万步** | 裸克隆无用（8.1%），但作 RL 先验极佳；冻结策略只训价值头防随机价值头毁先验 | 3 倍学习速度，换到新策略盆地 |
| **MPC 而非 MCTS** | 动作空间只有 18、模型精确、25FPS 帧级决策预算 80ms；MPC 定长 rollout 可完全并行且无树维护开销 | 零训练直接 96% |
| **网络剪枝 + 搜索**（混合体/P28） | 网络只负责"哪些动作值得看"，搜索负责"看清楚"——把两者的强项分开 | K=12 追平全量、快 4.3 倍 |
| **评分回归而非 argmax BC** | 多解任务里 argmax 标签自相矛盾（并列陷阱） | P19 8.9% → P21b 62.2% |
| **后悔值而非 top-1 准确率** | top-1 在中位 14/18 并列的标签上数学上限只有 11.9% | 网络 13.4% 已打满 top-1，实际 93.6% 决策够好 |
| **408/440 维手写物理观测**（含动作条件预演） | 标签问"往哪走能活"，观测里必须存在动作条件信息，否则网络结构上学不到排序 | P21a→P21b 的根因修复 |
| **MLP 1024×3（~2.5M）而非 CNN/RNN** | 三次对照证明瓶颈是信息和数据分布，不是参数量；老师标签是当前态的纯函数，用时序结构不公平 | 观测两针 +11 / 奖励八连败 / 大网仅 +1% / P18 CNN 22.5% |
| **DAgger 专家迭代** | 修闭环分布偏移——学生自打局的致死误判 9.2% vs 老师分布 6.4% | 首轮 +4，两轮见顶（预期形状） |
| **风险/价值头做分数微调，不做动作接管** | P27 的教训：接管式宏动作会打断本来正确的基础策略 | 宏动作 72.5% ❌ vs 分数微调 88.2% ✅ |
| **精确状态克隆 = 特权老师** | 只用于标注和回归 oracle，把老师从 96% 推到 99%，学生的上限才有得谈 | 120/120，297/300 |
| **双种子 1000+ 局定级 + 预注册判据** | 100 局评估系统性偏差 ±9 点，回调择优会过拟合运气 | P26 suppress-only：40 局 90% → 300 局 84% |
| **行为观察器（behavior observer）** | 把"看着弱"变成可计数的类别（missed_fire_window / stutter_stall / dead_end_stall / blind_fire / passive_map_control） | 人眼观感与仪表读数一一对应上了 |

## 四、目前有什么问题

### 1. 蒸馏鸿沟是主矛盾，且已被证明不是"数据不够"

老师 99% → 快速网络 88.2%，中间 11 点。填这道沟的三次正规尝试全部失败：
P29（标签语义混杂）、P29c（h48/h72/h96 平均出不决断的目标，验证 top1 仅 10.5%）、
精确老师蒸馏先导（三个候选全被在线门拒）。
**这说明差距来自"老师的决策依赖网络看不见的东西"，而不是样本量。**
精确老师用的是 RNG 和 Laika 隐藏状态——观测里根本不存在，蒸馏在信息上不封闭。

### 2. 行为质量和胜率脱节

88% 的官方分数下，300 局里仍有 `missed_fire_window ≈ 3400`、`stutter_stall ≈ 2100`、
`dead_end_stall ≈ 30–50`。人看录像的观感明显弱于 88%。
抖动/卡死本质是**单帧无记忆网络无法对一条路径做出承诺**。

### 3. 双亡 3–4% 仍是残余失败模式的主要成分

P27b 官方双亡 3.2%/4.2%；sparse 混合体唯一非胜（990008）也是双亡。

### 4. 99% 不可外推

精确老师读引擎内部状态，100% 只对固定基准成立；未见种子仍有 3 局明确失败。
**不能对外说"解决了这个游戏"。**

### 5. 对手单一，防守均衡问题没被裁决

全部训练和评测都对 Laika。免疫探针已经指出：Laika 太弱，老师怎样都碾压，
"这个游戏是否防守占优"必须靠两个强手自博弈才能回答。目前没有自博弈。

### 6. 工程债正在拖慢迭代

- `training/EXPERIMENTS.md` 停在 P25；P26–P30 和精确老师只散落在 `analysis/*.md`。
- 数字口径已经打架：README 主线写 `~68%(P22)`，而 STRATEGY 写 P22 重建后 74.7/75.6。
  **没有单一真相源**。
- `models/` 不入库 → 现任冠军（P26 iter05 + P27b 头）离开本机不可复现。
- `training/` 下 30+ 个 `run_*.sh`，一次实验一个脚本，没有统一编排和配置。

### 7. 算力天花板

单机 12 workers。一次官方定级小时级；P28 每局 25 秒，40 局要 20+ 分钟。
"想到一个点子 → 拿到可信答案"的周期是按天算的。

## 五、接下来怎么改进和发展

### A. 先还工程债（低风险、马上做）

1. **建立单一真相源**：把 P26–P30 + 精确老师补进 `EXPERIMENTS.md`，
   所有历史数字按最新重建值统一（尤其 P22 的 68 vs 74.7），
   另建 `CHAMPIONS.md` 只记录"通过协议的冠军 + 官方双基 + SHA256"。
2. **冠军可复现**：`p26_amortized_mpc_iter05.pt` + `p27b_risk_value_iter00.pt`
   走 Git LFS 或 release artifact（manifest 里已有校验和，直接用）。
3. **收敛脚本**：30+ 个 `run_*.sh` → 一个带 YAML 配置的 pipeline CLI，
   门控（40 → 300 → 1000+双基）作为流水线内置阶段，而不是靠人记住。
4. **行为指标进晋升门**：胜率不掉但 `missed_fire_window` 涨的候选，应当直接拒绝。

### B. 技术主线（按杠杆从高到低）

**1）老师侧：从定长单动作 rollout 改为短动作序列搜索** — 最高杠杆，已被 sparse 分析点名

现在的搜索是"选一个动作，重复 72 帧"。真实好棋是"先退两步再绕出去"。
保守第一版：两段精确 beam —— 先执行动作一个短 chunk，保留最好的安全状态，再分支第二个动作；
只在定长搜索受限或低价值时激活，正常延迟不变。
**门**：必须赢下 7 个硬种子（`975062`/`981086`/`991011` + `983043`/`983064`/`993007`/`993042`）
和 12 个控制种子，才有资格做广泛基准。

**2）学生侧：有界残差修正，默认弃权** — 唯一还没被证伪的蒸馏路线

不要再做全网络微调（已三次破坏冠军的分数校准）。
冻结 P27b 输出，只训一个从 `(观测, 先验动作)` 出发的网络，预测：
是否有高置信理由 override / 替代动作 / 两者的风险 / 默认 abstain。
**先量 override precision，再谈胜率。** 只有当三种子小屏保住胜率、开火频率、平均局长
同时降低失败类别计数时，才扩大采集。

**3）表征侧：给网络时序记忆** — 唯一没试过的结构性改动，且直接对准最大行为缺陷

`stutter_stall` / `dead_end_stall` 是"无记忆"的直接症状：网络每帧独立决策，
无法承诺一条 20 帧的逃生路径。最小实现：2–4 帧 frame stack；进一步可上小 GRU。
注意前提——老师标签必须同步变成序列一致的（这与方向 1 天然配对，应该一起做）。
历史上不上时序结构的理由是"老师标签是当前态纯函数"，方向 1 一旦落地，这个理由就失效了。

**4）承诺式 / 层级动作：把决策频率从每帧降到 action chunk**

P28 已经证明 12 帧动作承诺可行。把它做进快速网络：直接消抖动，
同时把推理成本降一个数量级（每 12 帧一次前向）。风险是躲弹反应变慢——
需要保留"高危中断"通道，用 P27b 的风险头做中断判据。

**5）自博弈裁决防守均衡**

让两个强手（P27b vs P27b，或 P27b vs 精确老师）互打，回答两个至今悬空的问题：
这个游戏是否防守占优？现在的策略里有多少是"过拟合 Laika 的具体弱点"？
这也是唯一能防止整个项目变成"专治 Laika"的手段。

### C. 长期外延

- **算力放大**：租多核 CPU，把每轮采集从小时级压到分钟级。
  这是唯一能让上面 5 个方向并行推进的杠杆——现在是串行等机器。
- **特征自举**：训感知网络从原始几何预测预演特征，替换 408 维手工前端，
  赎回"全知观测"的纯度（"网络自己长出眼睛"）。
- **在线平台视觉栈 V1–V3**：视觉 → 影子状态重建；观测契约已兼容（全部输入可从屏幕回推）。
  **仅限私房/本地对局**，公开匹配打真人 = 对人开挂。
- **论文**（`docs/PAPER.md` 骨架已在）：这个项目最有价值的其实是负结果群——
  并列陷阱与后悔值指标、价值叶子的泄漏与 on-policy 陷阱、课程分数不迁移、
  特权老师的信息不封闭。这些比"88% 胜率"更值得写。

### D. 明确的禁区（都已付过学费）

- ❌ 不要再做 blanket 规则/奖励微调（P13 空枪惩罚 / P26v8 硬例加压 / P27c 规则门，三次同型失败）。
- ❌ 不要在中途门宣称冠军（40 局 90% → 300 局 84%）。
- ❌ 不要混合语义不同的标签数据（P29 的直接死因）。
- ❌ 不要用课程分数做晋升判据（P24 全套）。
- ❌ 不要让辅助网络做动作接管，只让它调分数（P27 宏动作）。

## 六、一句话总结

项目已经把「RL → 搜索 → 蒸馏」三条路走通并量到各自的天花板，
**当前唯一的真问题是 11 点蒸馏鸿沟，且已证明它是信息问题不是数据问题。**
下一步的正确顺序是：先把老师从"重复单动作"升级为"短序列规划"（方向 1），
再用有界残差 + 时序记忆去接（方向 2+3）——而不是继续给现在这个单帧网络喂更多数据。
