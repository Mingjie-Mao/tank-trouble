# P24-P22 Replica-530 监控协议

## 进度与检查点

正式训练使用 `--collect-chunk 16`。每完成八个小块，即约 128 局，日志滚动输出：

- 命中间隔；
- 卡墙比例；
- 风格速率；
- 死亡、流干和到时比例；
- DAgger 阶段的老师后悔与致命误判。

每个小块独立保存。训练中断后，不加 `--fresh` 重启同一命令即可复用完成的小块。

日志：`training/logs/run_p24r530_replica.log`。

## 立即暂停条件

以下情况属于实现或数据异常，不等待阶段结束：

1. 老师累计至少 128 局后，命中间隔高于 4 秒；
2. 老师卡墙高于 12%；
3. 老师风格速率低于 +0.30/秒；
4. 数据出现 NaN、维度不等于 530、样本数停止增长；
5. 进程退出或连续两个检查窗口没有新检查点。

老师历史参照为约 2.3 秒/中、4.9% 卡墙、+1.04/秒风格。阈值刻意放宽，避免正常
种子波动触发误停。

## 不因单点停止

以下情况不能单独判定失败：

- 一次配对评测门下降；
- 一轮 DAgger 没有晋升；
- 验证 MSE 或精确 top-1 短期平台；
- 某一批新种子的命中间隔暂时变差。

P22 的有效曲线是 +4、+1、随后平台；历史 RL 也出现过确定性评测的假平台。因此候选
退化时只拒绝晋升，继续由旧冠军采集下一轮数据。

## 平台确认条件

只有同时满足以下条件，才认为不是假平台：

1. 至少完成两轮独立 DAgger；
2. 连续两轮配对原版胜率不晋升；
3. 学生平均老师后悔和致命误判没有下降；
4. 生存命中间隔、卡墙和风格指标没有一致改善；
5. 使用不同评测种子复验后结论不变。

在满足这些条件前，不因单轮结果停止整条流水线。

## 晋升目标

晋升按以下顺序验收，胜率不再作为连续优化分数：

1. **瞬时决策硬门**：单状态纯网络推理 p95 不高于 5ms；线上不调用 MPC。
2. **行为接近主目标**：候选的老师行为接近分必须高于当前冠军。
3. **强度资格线**：原版点胜率至少 55%，且 95% Wilson 置信下限高于 50%。

行为接近分由以下指标组成：

- 固定未训练状态上的老师评分后悔；
- 与老师最优动作精确一致率、5 分内近优动作率；
- 生存模式命中间隔与老师 2.4 秒/中的接近程度；
- 卡墙比例与老师 4.7% 的接近程度；
- 风格速率与老师 +1.08/秒的接近程度。

其中老师动作一致性占主要权重；命中节奏、卡墙和风格用于约束操作是否干净利落。
一旦通过强度资格线，58% 与 70% 的差距不为模型提供额外晋升优势。
