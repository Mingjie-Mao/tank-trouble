# P33：碰墙即死与同格超时即死课程

日期：2026-07-23

## 硬规则

P33 只修改训练课程，不修改最终原版验收：

- 任意一帧 `tank.hit_something` 为真，立即判定 `wall_death`，结算 0；
- 连续 50 帧（2 秒）没有离开当前迷宫格，立即判定 `cell_death`，结算 0；
- 跨入新格后倒计时清零；
- HUD 显示当前同格停留秒数；
- 规则观测提供 3 维：已用时间比例、剩余时间比例、上一帧是否碰墙。

硬死亡不能被命中分、进攻势能或风格分抵消。P33 老师在候选动作执行前按真实承诺
时长模拟规则，碰墙或将在当前格超时的动作直接屏蔽，而不是只在 reward 中扣分。

同格满 1 秒后进入强制离格规划。规划器先搜索直接跨格动作；若出生姿态或墙体几何
不允许，则搜索“先安全转向、再移动”的两段动作。

## 规则探针

未加入强制离格规划时，两个探针分别在第 50 帧和第 77 帧触发 `cell_death`，证明原地
摇头不能继续拖延或刷取收益。

加入两段离格规划后：

- 种子 `30000001`：240 帧内碰墙 0、无同格超时，跨格 4 次；最终因未命中流干；
- 种子 `30000002`：209 帧内碰墙 0、无同格超时，命中 3 次；最终被 Laika 击杀；
- 两局均不再发生硬规则死亡，但尚未形成稳定胜利老师。

出生点可行性使用 64 张独立地图检查：56/64 可以靠单段固定移动在 2 秒内安全离格；
剩余 8/64 需要先转向再移动；加入两段搜索后为 64/64 可行。该结果只证明出生点没有
被规则天然判死，不证明完整战斗路线都可泛化。

## 七问审计

1. **目标：黄色。** 硬规则准确表达“不能顶墙、不能在一格内摇头等待”，但它本身
   不等于主动击杀，还可能诱导贴着格线往返。它只能作为反作弊约束，原版胜利和观赏性
   仍是最终目标。
2. **信息：黄色。** P33 在线老师能看到墙体、当前格和倒计时；3 维规则特征也已经
   定义。现有 P30 学生尚未扩充这 3 维，因此不能直接拿旧网络继续训练。
3. **表示：黄色。** 动作空间可以表达安全转向、跨格和开火；P33 老师也能表达两段
   离格计划。最终前馈学生还必须加入上一承诺动作和剩余承诺时间，否则会重新变成逐帧
   摇摆。
4. **经验：红色。** 当前只有规则失败轨迹、合法离格轨迹和少量命中，尚无足够的
   “持续合法跑图→制造炮线→安全击杀”完整成功数据。不能现在就蒸馏。
5. **学习信号：黄色。** 碰墙和超时在违规帧立即终止，候选屏蔽把责任定位到当前
   动作，credit assignment 清楚；但主动击杀部分仍稀疏，跨格本身也不能作为无限收入。
6. **优化：红色。** 老师已经能遵守硬约束，但两张战斗探针分别流干和被击杀，说明
   当前计算预算下还不能稳定到达“合法且果断击杀”的策略盆地。
7. **泛化：红色。** 64/64 出生点可安全离格，只排除了明显的规则不可行；完整战斗
   只检查两张图，尚不能证明路线、攻击或硬规则策略跨地图泛化。

## 当前判决

硬规则可以保留为 P33 课程，因为它确实终止了原地摇头和顶墙刷分，而且出生点两段
动作可行性为 64/64。P33 不能立即用于学生训练：应先让老师在多图上稳定产出不触发
硬死亡且包含主动命中的完整轨迹，再把规则 3 维与承诺状态一起加入学生观测。
