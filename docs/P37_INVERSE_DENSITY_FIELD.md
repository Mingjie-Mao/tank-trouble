# P37.1 反演弹道密度场与指数追猎链老师

## 目的

用地图与 Laika 当前格子生成一个非人工指定的击杀场。反向子弹能够经过的
射手格越多、角度窗口越宽，该格的密度越深。老师沿密度梯度移动，在高机会
区域可以继续爬升或对准见证炮向；是否开火最终由正向物理推演决定。

静态指数等高线在场外和同层内可能没有梯度，因此 P37.1 在短时击杀密度上
构建迷宫距离包络，并用三秒指数“追猎链”恢复连续跑图动机。

## 场域规则

从 Laika 格子中心确定性均匀发射 `N` 条反向射线，最多反弹 `n` 次，最长为
75 帧（3 秒）。超过有效飞行时间才可能命中的长弹道不进入场域。反向轨迹点
`x` 和方向 `u` 对应的坦克中心为：

```text
p = x + (4.5 / 16) * scale * u
```

每条射线对每个格子最多投一票：

```text
H(c) = sum_i I[ray_i reaches a legal shooter centre in c within 75 frames]
```

公开场保留原始计数 `H(c)`。老师把 `log(1 + H)` 等分为七层，层值为：

```text
0, 1, 2, 4, 8, 16, 32, 64
```

场域层值只按变化量计分；留在原地不会持续获得奖励。

## 导航包络与追猎链

每个短时射击格 `z` 的源质量同时考虑射线计数和最短飞行时间：

```text
q(z) = log_density(z) * (0.5 + 0.5 * exp(-min_flight(z) / 75))
```

对所有可达格构建：

```text
B(c) = max_z q(z) * exp(-0.18 * maze_distance(c, z))
```

只要存在短时射击格，`B` 就覆盖整张可达地图。从任意非峰值格都能沿迷宫
最短路找到一个更高邻格；包络的局部峰值必须本身是短时射击格。

坦克主动进入一个尚未收集过、并且 `B` 严格更高的格子时，触发一次追猎链：

```text
1, 2, 4, 8, 16, 32, 64
```

三秒内继续上坡，倍率继续增长；超时后从 1 重新开始。每个 `(Laika格子,
玩家格子)` 在当前回合只能收集一次，因此下坡再上坡不能刷分。Laika 换格
造成的场域变化不触发奖励，只有玩家实际换格并上坡才算。

追猎链是纯正奖励，不恢复“进入区域却不攻击”的负规则。它的作用仅是持续
奖励朝及时击杀区域跑图。

## 时效与开火规则

格子的短时几何成功率由 `H(c) / N` 给出。它只用于描述场域深度、瞄准收益和
错误开火的代价，不再产生“进入区域却没有尝试击杀”的负奖励。

原因是二值的“存在弹道”不能证明当前值得尝试；路径时间已在建场阶段作为
硬条件处理。开火没有人为分数门槛；真实正向弹道确认当前一发能命中时立即
开火。错误开火和自杀弹道仍分别扣分。反演只生成场和炮向，最终命中始终由
原版正向物理裁决。

## 复杂度

设射线数为 `N`，最大反弹数为 `n`，墙盒数为 `W`，总射程按 `delta` 间隔
栅格化，则单次建场复杂度近似为：

```text
O(N * ((n + 1) * W + L / delta))
```

空间复杂度约为 `O(map_cells * aim_bins)`。场按 `(本回合地图, Laika格子)` 缓存，
只在 Laika 换格时首次重建。

导航包络额外需要 `O(firing_cells * reachable_cells)`；当前地图最大约120格，
相对于射线追踪开销很小。

本机 seed `37500001` 实测：

- 512 射线：约 80 ms/首次建场；
- 2048 射线：约 300 ms/首次建场；
- 512 射线老师含追猎链 MPC：平均约 33 ms/游戏帧。

## P37 学生观测

学生保持 `801 -> 1024 -> 1024 -> 1024 -> 18` 的网络形状。前 667 维
仍是 P29 物理、生存账本、前沿与开火事实；原 P36 的 134 维
金币课程输入被整体替换为：

```text
120 维：世界坐标的导航包络 B(c)
  9 维：当前包络值、相对密度、层级、指数值、最短弹时、
         炮向集中度、追猎链层数、剩余时间、上次链奖励
  5 维：下一个上坡路点的本地前/右方向、到主导射击格的距离、
         最佳炮向的相对 cos/sin
```

新增列的一层权重从零开始，因此可从 667 维 P29 actor 无损
warm-start。P35/P36 的 replay 与 actor 虽然也是 801 维，但末尾 134 列
语义不同，编码器会明确拒绝将它们当作 P37 warm-start。

```bash
python3 training/watch.py --policy p37-killfield-teacher --seed 37500001 --field-rays 512 --field-bounces 2 --field-flight-frames 75
```

P37 回放保留原版回合状态机：死亡后先继续运行 75 帧（3 秒），随后

移动/转向动作（不继续开火），而不是因为策略返回空动作立即停住。

## P37 短蒸馏

金币实体已删除，但被验证过的连续指数结构保留为追猎链：连续进入
新的严格上坡格得到 `1,2,4,...,64`。学生的 120 维包络图现使用符号
同时公开一次性账本：未领取格为正 `B(c)`，已领取格为负 `-B(c)`。

蒸馏复用 P21 成功管线的三个原则：同一状态的 18 动作共用成对前推
RNG；回归完整评分地形而不只是 argmax；只在宏动作重新规划帧采样。
学生部署时使用与老师相同的短宏动作执行器。主动击杀轨迹权重最高，
对手自杀仍保留但降权，双杀轨迹显著降权。

当前短版使用 40 局、3,564 个宏决策样本、12 轮拟合，权重保存为
`training/models/p37_killfield_student_short.pt`。按人工回放要求，未做学生胜率测评。

```bash
python3 training/watch.py --policy p37-killfield-student --seed 37850001 --field-rays 512 --field-bounces 2 --field-flight-frames 75
```

## P37 完整单网络蒸馏与 DAgger

正式学生把观测扩展为 914 维：

```text
801 维：P29 完整物理/战斗事实 + P37 带一次性账本的击杀场
 90 维：9 种移动候选 x 10 个物理事实
          (终点包络/梯度/场值/峰值/密度/炮向对齐/集中度/
           追猎链收益/实际位移/实际转角)
 23 维：上一动作、实际动作效果、位移/转向失效、连续失效时间、
           宏动作剩余时间与已承诺动作
```

这 90 维是动作条件物理事实，不包含老师价值或决策。它避免要求 MLP
从墙位图中自行重建反弹、炮向直方图和追猎链后果。部署策略只有一个
`914 -> 1024 -> 1024 -> 1024 -> 18` MLP 输出决策评分；运行时不调用
`density_rollout` 或 MPC。最多 4 帧的宏动作执行器只保持网络上次选择，
观测到动作失效、撞墙或精确开火机会时会提前请求网络重新决策。

完整流水线使用：

```text
老师启动： 96 局  -> 10,208 样本 -> iter00
DAgger 1：   48 局  ->  9,248 纠错 -> 19,456 聚合样本 -> iter01
DAgger 2：   48 局  ->  6,237 纠错 -> 25,693 聚合样本 -> iter02
```

最终网络含 3,054,610 个参数。工程验证中强制令老师评分函数抛异常，
学生仍能独立输出合法动作，证明部署路径不依赖 MPC。

```bash
python3 training/watch.py --policy p37-killfield-full --net training/models/p37_killfield_full.pt --seed 38500001 --field-rays 512 --field-bounces 2 --field-flight-frames 75
```
