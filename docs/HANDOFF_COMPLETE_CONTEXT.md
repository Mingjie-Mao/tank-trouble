## 2. 项目最终目标

1. 从 Flash 反编译源码出发，尽量 1:1 复刻 Tank Trouble 的迷宫、坦克、子弹和 Laika。
2. 训练一个可以在原版规则下稳定击败 Laika 的纯神经网络策略。
3. 最终部署不能依赖 MPC 搜索；物理事实预演特征可以使用，但不能把未来价值或隐藏 RNG
   直接泄漏给网络。
4. 不只追求胜率，还希望策略主动寻路、主动制造击杀、少卡墙，打法有观赏性。

最重要的验收铁律：训练课程可以改规则，但最终结论永远看原版游戏的真胜率。原版口径中，
先杀死 Laika 后自己又被余弹击中属于双亡，不算胜利。

## 5. 实验时间线与结论

### 5.1 2026-07-05 至 2026-07-06：原版复刻与 RL 奖励线

完成 Python 环境、真规则评测、弹道预演观测和 PPO 训练。奖励工程从约 12% 推到 P8 的
35.1%，随后进入平台。P13 收紧空枪惩罚虽然提高命中率，却将胜率降到 27.7%，说明火力
体量是承重墙。P14 闪避特训降低双亡但练出被动策略，进一步证明单点行为矫正有副作用。

### 5.2 2026-07-07：MPC、蒸馏和专家迭代

全量 MPC 用 18 个候选动作、48 帧沙盒前推直接达到约 96%，项目从纯 RL 转向“搜索老师
+ 蒸馏”。P19 argmax 行为克隆失败；P21a 评分回归也失败，定位到动作条件信息不在观测中。
P21b 增加到 408 维全知观测后达到 62.2% / 63.8%。P22 用 DAgger 进行三轮专家迭代，
曲线为 +4 / +1 / 平台，iter02 成为当前冠军，说明纯 DAgger 大约在 68% 见顶。

### 5.3 2026-07-08 上午：P23 与“老师是否主动”的诊断

P23 给 MPC rollout 加学习价值叶子，老师胜率由 93.5% 降到 87.5%，且更被动。原因是按
状态而非按局切分导致地图泄漏，以及 on-policy 价值把现有防守型策略固化。

随后加入 Laika 自伤免疫探针。取消 Laika 自杀后，老师胜率没有下降，反而约为 97.9%，
证明老师绝大多数胜利来自主动击杀，而不是等待 Laika 自杀。真正问题是老师约 96% 到学生
约 64% 的蒸馏鸿沟，而不是老师没有进攻。

### 5.4 2026-07-08 下午：P24 生存课程

用户提出：Laika 无敌，我方一发即死，命中 Laika 给时钟续命，以存活时长训练“边躲边猎”。
40 局机制验证中，空闲策略平均存活 186 帧、0 命中；生存 MPC 平均存活 686 帧、15.1 次
命中，说明课程确实逼出了主动狩猎。

随后用户认为时间条单局过长且不能评价观赏性，提出类似 MOBA 赛后评分的衰减计分板。
P24v2 最终经济为：起始 100、每秒衰减 10、命中 +50、BFS 追击势能、首访新格奖励、
卡墙税、死亡清空结算分、30 秒上限，并保留命中账、风格账和时间税遥测。

四方对照结果：

- 空闲：结算 0，不能靠挂机生存。
- Laika 镜像：风格速率 +1.51/s、卡墙 1.1%，作为移动观赏性锚点。
- 纯狩猎老师：1.8s/次命中、卡墙 42.6%、风格速率 -0.73/s。
- 风格老师：1.6s/次命中、卡墙 4.4%、风格速率 +1.10/s、结算分 562。

这证明风格项不是和杀伤力做交换；势能导航让老师同时更好看、更能打。

### 5.5 P24v2.1 蒸馏最终结果

过夜管线实际已经完成，但旧台账还写着“在跑”。日志是
`training/logs/run_p24_pipeline.log`：

- 采集：1496 局，361,299 样本。
- 网络：410 维观测（408 + 分数池 + 剩余时间），top-1 23.3%，top-3 51.4%。
- 生存课程验收：平均只活 9.2 秒，84% 流干，命中间隔 41.9 秒。
- 原版 300 局：真胜率 58.7%，负 32.0%，双亡 8.3%，平 1.0%。

判定：P24v2.1 没有超过 P22。双亡率较低说明躲余弹能力没有彻底崩，但网络没有学会老师
持续狩猎的动作排序。P22 仍是冠军，`p24_scorenet.pt` 只是负结果模型。

### 5.6 2026-07-13：P25 原版机会课程先导

用户观察 P24v2.1 学生仍倾向防守，提出不再奖励单纯移动，而是奖励战局向有效击杀推进：
获得可信炮线、缩短到下一射击位的路径、安全接敌、制造压力、机会出现后及时开火，并要求
所有指标是不可绕圈刷取的势能差或事件，且训练始终使用原版规则。

新增 `training/opportunity_distill.py`。老师评分为原版终局价值 ±1000，加机会势能差；势能
包含可信炮线、到最近直接射击位的 BFS 进度和来弹风险。学生观测为 440 维：P21b 408
维物理观测，加当前机会事实 5 维和九种移动的动作条件机会预演 27 维。

先导结果：

- 机会老师在 64 局、5% 移动噪声下真胜率 93.8%，双亡 4.7%，说明塑形没有破坏老师。
- 64 局老师自打数据（10,024 样本）直接蒸馏后仅 13.8%，出现严重闭环分布偏移。
- 再用 P22 冠军走 64 局、由机会老师重标，聚合到 25,441 样本后，学生原版 80 局升到
  52.5% 真胜、38.8% 负、8.8% 双亡。
- 训练集上中位后悔为 0、77.7% 决策后悔不超过 25 分，但致死误判仍为 6.27%。学生选择
  开火 11.9%，老师只有 2.7%，说明主动性部分被学成过度开火。

判定：机会课程的老师目标成立，DAgger 也显著修复了首轮崩溃，但当前学生低于 P24v2.1
的 58.7% 和 P22 的约 68%，不能晋升。下一步必须先和用户讨论“无可信炮线时的极小开火
并列破除”或机会门控，不能直接加入 P13 式 blanket 空枪惩罚。

### 5.7 P25v2：360 度反弹炮线老师

用户指出敌人可能位于坦克背后，±30° 的七条假想弹道会漏掉必须转身才能利用的反弹杀线。
新增 `training/opportunity_teacher_v2.py`，按坦克真实的 32 档朝向扫描全周弹道，仍预测
75 帧、最多两次反弹。不能只把全周最大炮线质量直接作为势能，否则坦克转向前后势能不变；
因此新版同时考虑最佳炮线质量和炮口对准程度。背后炮线先提供 25% 机会底值，向正确方向
转动逐步获得完整炮线势能。

机制探针 seed12 中，最佳炮线位于炮口后方 123.8°；正确方向转动 16 帧使势能增加
13.35，反向增加 7.25。随后在全新种子 @972000 跑 100 局原版真口径：98.0% 真胜、
2.0% 负、0 双亡、0 自杀、0 平局；场均开火 4.6 发、移动 8.0 格、平均局长 12.7 秒；
击杀方式为直射 23%、反弹 77%。这说明全周扫描没有把老师带成等待流，并显著提高了反弹
机会利用率。100 局仍不是协议要求的 1000+ 正式定级，但足够支持进入 v2 蒸馏。旧 P25
数据和模型保持原样，v2 使用独立 `training/opportunity_data_v2/`，不能混合语义不同的特征。

新增 `training/opportunity_distill_v2.py`：采集 128 局老师分布、128 局 P22 分布并由 v2 老师
重标，从零训练后做两轮各 128 局学生 on-policy DAgger；学生仅在网络偏好开火且对准后的
可信炮线不低于 0.58 时开火。2026-07-13 推送前的进行中快照：初版学生在 80 局固定评测门
真胜 66.2%，第一轮 DAgger 后升至 70.0%；第二轮采集现场真胜 75.0%，`iter02` 候选已经
生成，尚待评测门与最终 200 局原版验收。这些是中途结果，不是冠军定级。

## 6. P24 v3 首轮验证

用户提出并认可三个方向，本轮已实现：

1. Laika 每次被命中后进入 2 秒免疫；免疫期间后续子弹穿透、不消失。目的不是降低难度，
   而是消除贴脸连续刷命中，逼老师反复练习“接近—出手—脱离—重新接敌”。
2. 我方 5 发子弹全部在场时，每秒额外扣 5 分。罚的是弹尽状态，不是开火动作，以避免
   重演 P13 的火力萎缩；如果命中间隔恶化到 2.5 秒以上，应先减半到 -2.5/s。
3. 静止行为先测不罚。按 1 秒窗口内净位移小于 0.3 格统计静止帧比例。

实现约束：

- 免疫计时必须在真实引擎和 MPC 沙盒中完全同步。
- 免疫剩余比例必须进入未来蒸馏观测，410 维变 411 维。
- 第一轮只跑四方机制对照，不直接重采集 1500 局。
- 通过条件：连续刷命中被压制，命中间隔不明显差于 2.5 秒；卡墙维持低位；静止率得到
  可解释的实测；命中能力不能因弹夹税塌陷。

2026-07-13 四方各 40 局结果：

- idle：7.4s，0 命中，静止 100%，结算 0。
- Laika 镜像：9.6s，15.4s/中，风格 +1.59/s，卡墙 1.4%，空弹夹 5.4%，
  静止 46.1%。
- hunt：12.9s，8.9s/中，风格 -0.92/s，卡墙 49.8%，空弹夹 23.3%，
  静止 49.6%，80% 流干。
- style：17.9s，8.1s/中，风格 +1.34/s，卡墙 4.7%，空弹夹 22.6%，
  静止 47.5%，68% 流干，风格效率指数 0.85。

判定：**2 秒免疫 + -5/s 空弹夹税的当前组合失败，不能直接重训。** 与 P24v2
style 老师的 1.6s/中相比，杀伤节奏恶化到 8.1s/中。主要结构原因是免疫 50 帧比
MPC 视野 48 帧还长，命中后老师在整个可见未来中都看不到下一次合法命中奖励；穿透弹
继续占用弹槽，又使约 23% 帧处于空弹夹状态。风格导航仍有效，因此卡墙和风格速率没有
一起崩，但它救不了主粮断裂。

静止遥测也推翻了原来的绝对阈值：Laika 镜像自身已有 46.1% 静止，style 为 47.5%，
所以不能用“超过 25% 就罚”。若以后继续研究静止，应相对 Laika 基线比较，并区分正常
瞄准停顿与无效站桩。

建议的下一步不是长训，而是先和用户讨论一个小消融：优先缩短到 1 秒免疫，并比较
空弹夹税 0 / -2.5/s；若坚持 2 秒免疫，就必须把老师视野提高到 64 或 96 帧，但这会
增加采集成本，也可能扩大老师到学生的蒸馏鸿沟。
