# P41 击杀后目标函数塌陷（**已知回归，未修复**）

> 状态：`training/killfield_teacher.py` **当前带着这个回归入档**。
> 接手前先读完本文，不要以为击杀后的呆滞是随机现象。

## 背景：为什么动这块

用户对击杀后求生机制的批评：

> 「他这个状态机切状态太伤了，感觉是你在约束 AI 打游戏。」

原实现在 `act()` 里有一整段独立分支：对手死亡后换一套打分函数
（`post_kill_survival_scores`）、换 horizon、强制不开火、独立的 commit 逻辑。
75 帧里等于换了一个 AI，违反「不要教 AI 玩游戏」。

## 病根：搜索在击杀那一帧闭眼

`density_rollout` 原本在击杀帧直接 return：

```python
if not enemy.alive:
    return ACTIVE_KILL_SCORE - 8.0 * frame   # 早退
```

引擎实际还要跑 75 帧（`NUMBEROFFRAMESBEFOREEND 125 − NUMBEROFFRAMESFROZEN 50`），
期间飞行中的子弹仍可致死。更关键的是风险项写在这个 return **之后**：

```python
score -= RISK_WEIGHT * analyzer.incoming_risk(sandbox)
```

所以一旦击杀，风险评估被整段跳过——「杀完停在弹道上」与「杀完躲进安全格」
得分完全相同。手写状态机存在的唯一原因，就是补这个洞。

## 改动内容

1. `density_rollout` 不再在击杀帧 return，记账后继续推演；期间死亡照常返回 `DEATH_SCORE`
2. 存活走完窗口时返回 `kill_score − RISK_WEIGHT × incoming_risk`
3. 新增 `NullDensityField`：所有格子 `in_bounds` 恒为 False，狩猎项自动归零
4. 删除 `act()` 的整段击杀后状态机（含 `post_kill_hold` / `post_kill_plan` 两种决策类型）
5. `scores()` 在对手已死时把 horizon 从 36 拉到 75（搜索深度，非目标函数）

## 回归：目标函数是一张平面

**预期**：目标没了之后，死亡罚分 + 火力风险自己构成求生目标。
**实测：这句话是错的。**

卡墙那一帧，10 个有效候选的完整分值：

| 候选 | 新（空场） | 旧（状态机） |
| --- | ---: | ---: |
| 后左 | **1500.00** | 12091.78 |
| 后直 | 900.00 | 12091.88 |
| 静直 | **1500.00** | 12092.08 |
| 前右 | **1500.00** | **12097.11** ← 旧的选这个，能脱困 |
| 其余 6 个 | **均为 1500.00** | 12065–12098 各不相同 |

* 10 个候选里 **9 个精确等于 1500.00**（`OPPONENT_SELF_SCORE` 原值），
  说明 `incoming_risk` 对每个候选都返回 **0**
* 极差 600 全部来自卡墙罚分 `NO_EFFECT_REPEAT_PENALTY`，不是真实区分度
* 旧路径极差 3031，选「前右」；新路径 argmax 在平面上乱选，选中「后左」

后果：击杀后 75 帧里坦克 `x=387.4 y=206.2 朝向=44.0` **一个数都没变**，
动作在两个无效指令间来回跳（罚分导致交替）。回放里看是一具雕像。

## 根因

`OpportunityAnalyzer360.incoming_risk` 建模的是**对手的开火机会**，
不是**已经在飞的子弹**。对手死了，它按定义恒为 0。

而这 3 秒里唯一的威胁恰恰就是飞行中的子弹（存活 250 帧 / 10 秒，且不分敌我致命）。
**世界模型里缺了这一项**，不是打分权重的问题。

## 连带发现：想象中的击杀

检测器：真实对手存活时，若候选分数落进击杀分段，说明该次前推里沙盒对手死了。

```
1183 次决策中 174 次出现想象击杀          (14.7%)
其中候选间完全打平、真的没有梯度  89 次   (占 51.1%)
普通帧分数极差   中位数  600.00   ← 正好等于卡墙罚分
想象击杀帧极差   中位数 2494.58
```

约 **7.5% 的决策**在为一个没发生的胜利打分，且此时选择是任意的。
注意这是**对 Laika 测的**——沙盒模型与真实对手完全一致的最有利情况。
换成真人，沙盒里的 Laika 会在真人不会死的局面里死掉，14.7% 只是下界。

## 修复方向（未实施）

1. **别把想象中的击杀按确定性计分。** 现在预测到击杀就给 12000 常数，
   等于把预测当既成事实。改成按置信度折扣，平面塌陷和幻觉击杀一起松动。
2. **让 `incoming_risk` 看见飞行中的子弹**（不分归属）。这是补世界模型，
   不是给 AI 加战术规则。
