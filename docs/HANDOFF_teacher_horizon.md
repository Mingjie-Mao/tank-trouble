# 交接：验证"老师短视 → 学生消极"假设（给队友 + agent）

> 这份文档是自包含的。可以直接把 **§6 的任务块**贴给一个 agent 让它执行。
> 验证**老师侧改造能否把 AI 从"反打手"变成"猎手"并抬高天花板**。

## 1. 一句话背景

本项目把 Tank Trouble 1:1 复刻，用 **MPC 搜索老师**蒸馏出一个纯反应网络
（现任冠军 `scorenet_best.pt`，真胜率 ~62-66%）。搜索老师 96%，学生在逼近它。
**关键：学生的"性格"是老师评分函数的镜像。**

## 2. 要验证的假设（可证伪）

> **H：学生"身法好、瞄准可以、但进攻欲望弱、不主动跑图"，是因为 MPC 老师
> 本身短视——48 帧(~2s)地平线 + 死亡/击杀 ±1000 主导 + 存活项只有
> −0.5×路径距离的微弱靠近奖励，使老师本身就是个"生存主义反打手"。
> 因此加长老师地平线（48→96→144）会让老师更主动，学生随之更主动，
> 且天花板上移。**

**推论（这条最重要）**：纯 DAgger 迭代**改不了**这个性格，只会让反打更精。
要改性格必须动**老师**，不是动蒸馏轮数。

## 3. 证据链（为什么这么猜）

- 定级分解：**胜 62.2% / 负 28.8% / 双亡 8.2% / 平局 ≈0.8%**。
  平局仅 0.8% → **不是龟缩耗时**，局面都打出结果 → "消极"实为"反打而非狩猎"。
  但**大头残差是 28.8% 的被打死**，不是错失进攻。
- 老师评分（见 `training/mpc_agent.py:91` `rollout()`）：
  - 死 `-1000+t`，杀且活 `+1000-t`，存活到期 `-0.5*路径距离(+敌死 800)`。
  - 2 秒内躲弹=几乎确定避免 −1000（强信号→神身法）；主动跑去杀=够不着，
    +1000 触发不了，只剩 −0.5×距离（10 格才 −5，对 ±1000 可忽略）。
  - 叠加**双亡不计分**（真实规则），激进换命被判作废 → 老师理性地选择反打。

## 4. 验证步骤（从便宜到贵，逐级加码）

**关键便利：MPC 老师是纯搜索、零权重**，改地平线**不需要任何模型文件**，
干净 clone 就能复现 §4.1–4.2。只有 §4.3 重蒸馏才需要算力。

### 4.1 便宜①：先给"消极是否亏"定性（不改任何代码）
统计当前学生/老师的失败归因：28.8% 的死里，多少是"保守错失先手被反杀"
vs "开局劣势本就难赢"。方法：跑 N 局，逐局记录 [双方首次开火帧、死亡时
双方距离、死亡前 30 帧我方是否在靠近敌人]。若大量败局属于"被动等待→被抢先手"，
则进攻性有价值；若多为开局劣势，则消极接近最优、天花板是"反应受限"而非"老师受限"。

### 4.2 便宜②：老师地平线扫描（核心实验，无需重训）
直接跑不同地平线的 MPC 老师，同一批种子，测**胜率 + 进攻代理指标**：
```bash
python3 training/mpc_agent.py --n 300 --opp-model L2 --horizon 48   # 基线
python3 training/mpc_agent.py --n 300 --opp-model L2 --horizon 96
python3 training/mpc_agent.py --n 300 --opp-model L2 --horizon 144
```
**进攻代理指标**（agent 需在 rollout/对局里加测量，或用 watch 观察）：
- 平均"我方↔敌方"距离（越小越主动狩猎）
- 地图格覆盖率（走过的不同格 / 总格数，越高越"跑图"）
- 首次开火/首次接敌的主动性（是否更早压上）
- 平局率（必须仍 ≈0，否则加长视野把它变成了拖延）

> ⚠️ 加长地平线会让 rollout 变慢（线性）、且随机博弈里长程对手预测更噪，
> 可能有甜点位。horizon 变了 **hold 也可考虑同步放大**（如 hold=24/32）。

### 4.3 贵：若 §4.2 老师"更主动且不更弱"，才重蒸馏验学生
用胜出的地平线重跑采集 + 训练，看学生是否**继承**了主动性：
```bash
# 改 score_distill.collect() 与 expert_iter 的 horizon/hold 后
python3 training/score_distill.py probe --rounds 3000 --workers <核数-2>
python3 training/score_distill.py eval --net training/models/<新网>.pt --n 1000 --seed 970000
```
horizon/hold 的**全部调用点**（改实验时都要对齐）：
`mpc_agent.py:91,140` · `score_distill.py:134,153` · `expert_iter.py:91,119` ·
`hybrid_agent.py:34,86` · `watch.py:93`。

## 5. 判定标准（给 agent 明确的成功/失败信号）

- ✅ **证实 H**：长地平线老师"我↔敌距离显著下降 + 覆盖率上升"（更狩猎）
  **且**胜率≥基线；重蒸馏后学生同样更主动且胜率上移。→ 天花板是"老师受限"，
  加长视野是有效杠杆，写进论文的"天花板分解"。
- ❌ **证伪 H（同样有价值！）**：长地平线老师**没更主动**（距离不变），
  **或**更主动但**胜率下降**（激进被双亡规则惩罚）。→ 消极接近最优，
  天花板是"反应受限"，别再往进攻性上砸算力。
