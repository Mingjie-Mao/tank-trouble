## 关键结论
1. destroy 口径系统性虚高 (v2: +29 点); 训练目标必须用原版计分 (v4 起)。
2. 只改激励 +1.7 (v4); 给弹道几何观测 +8.3 (P2) —— 缺信息不缺激励。
3. 地图去偏与密集闪避压力各 +1.4~3.0, 行为指标 (移动/自杀/双亡) 同向改善。
4. 模型已会反弹杀 (56% 击杀经反弹), 命中率 12.6% 仍是泼弹型, 待改进。

| P4 长训 (6M 提前停) | 同 P4, 恒定 lr 3e-4 | 300 | 51.3% | 29.7% | 30.7% | 22.3% | 12.8% | 5.0 | 62% |

## 重要发现: 长训不涨的模式
P2 长训 (30.4->29.8) 与 P4 长训 (34.8->29.7, 6M 提前停) 同型:
3M 探针吃到新改动红利后, 恒定 lr 3e-4 续训只在最优附近震荡甚至回退。
=> resume 已支持 --lr 覆盖 (custom_objects), P5 用 1e-4 精修验证该假设。

## 终审 (2000 局, 970000 新种子)
**冠军 = p8_badshot_best: 真胜率 33.4% ± 2.1%** (先杀率 52.1%)
双亡 27.3 / 自杀 19.6 / 命中率 12.1 / 移动 5.7 格 / 反弹杀 57%
夜间累计: 22.1% (接手) -> 33.4% (终审), +11.3 个点, 全部单变量可溯源。

- P13 (空枪纪律: waste -0.10 / near-miss 0.02) 定级: 27.7% => NO-GO (-7.4)
  录像观察"泼弹"的直接矫正尝试。命中率 15.4% 史上最高、场均开火 4.3->2.9,
  纪律确实生效——但真胜率反降: **火力体量本身是承重墙** (泼弹的压制迫使
  Laika 躲避而非还击), 压泼弹丢掉的压制值 > 精度收益。回调 3M 报 34% 又虚高。

- P14 (闪避特训营 2M 缴械 + 3M 全规则微调 lr1.5e-4) 定级: 25.8% => NO-GO (-9.3)
  特训本身有效: 缴械存活 6.7s->9.4s(+42%), 最长 19s->42s; 迁移也真实发生:
  双亡率 19.6% 史上最低(冠军 26.2), 反弹杀 66% 史上最高。但代价是被动:
  零开火局 21%, 场均 2.5 发, 真负率 54.6%。隔离练出的"苟"字诀在联合任务
  是负资产; 微调曲线全程未超 P13 从零对照。若再试: 限弹特训(1发)而非缴械。

## P13/P14 后的结论更新 (2026-07-06)
P8 之后连续 8 针 (P9-P14) 全部 NO-GO; P13/P14 进一步证明"矫正泼弹/补身法"

## 突破: 容量才是瓶颈 (2026-07-07)
P8 后 P9-P16 全灭 (奖励/课程/模仿/自博弈), 一度以为 35% 是天花板。
**P17 (512 宽网络从零 12M) 终审 38.3% (2000 局) => 新冠军, 击穿 35% 墙。**
诊断: 256 网装不下"压制+精确"两套技能 (P13 推精确丢压制/P15 导精确丢机动);
512 网同时装下 —— 命中率 12%->16.5%, 场均开火 4.3->3.4 (打更少中更多),
反弹杀 59%, 自杀 19%。瓶颈从来是表达容量, 不是策略选择。
- p17_net512_best.zip: 512 网从零 38.3% (2000 局).
- **P18: 冠军 + 观测 v3 运动学 (--obs-kin 128 维): 42.1% (1000 局) => 新冠军 +3.8。**
  补: 自身速度+卡墙旗标 (贴墙盲区) / 最短路下一格方位 (跑图方向) / Laika 速度 (预判躲闪).
  零列扩展热启动, lr 2e-4 微调 6M. 行为验证: 场均移动 5.2->3.7 格 (动更少赢更多,
  贴墙抖动被治), 零开火局 11->7% 史上最低, 先杀率 59% 史上最高, 命中 15.9%.
  注意: 末段 lr 2e-4 崩到回调 28%, 最佳锁在 2M 峰值快照 (p18_kin_best).
- **P19 (P18 峰值 + lr 1e-4 + ent 0.005 续训 6M): 46.3% (1000 局) => 新冠军 +3.7。**
  低 lr 高熵治好了 P18 末段崩盘, 干净收尾。先杀率 64.6% / 零开火 6% 均史上最佳。
- [进行中] P20: 读心作弊 (--obs-mind +12 维): 直读 Laika 目标类别/动作栈/目标坐标。
  用户明确要作弊(有白盒代码), 最致命特征 = driveToPos 预知它未来 10 帧位置。
  零列扩展热启动, lr 2e-4 微调 6M. 预估 +5~8。
